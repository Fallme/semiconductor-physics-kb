第1章 半导体中的电子状态

能带理论与电子运动 — 全书理论基石

权重95%★★★★★
📊 知识关系图 — 第1章
1
晶体结构
★★★☆☆

金刚石结构：Si、Ge等元素半导体。可视为两个FCC子晶格沿体对角线位移1/4嵌套，每个晶胞含8个原子（4基元×2）。

闪锌矿结构：GaAs等化合物半导体。两套FCC子晶格由不同原子占据。

纤锌矿结构：GaN、ZnO等。六方密堆积，原胞含2个原子。

记忆：金刚石=同种原子+FCC；闪锌矿=不同原子+FCC；纤锌矿=六方密堆积

布拉伐格子：晶格周期性的数学描述，共14种。半导体中常见面心立方(FCC)和六方密堆积(HCP)。

晶向指数：[hkl]表示晶向，(hkl)表示晶面。常见：<100>、<110>、<111>。n型Si <100>方向生长。

原子共有化运动：晶体中原子外层电子受相邻原子势场影响，在整个晶体中运动，形成能带。

2
能带理论
★★★★★

孤立原子分立能级 → 晶体中周期性势场 → 能级分裂 → 形成准连续能带

导带(E_c)：电子自由运动的能带
价带(E_v)：共价键电子所在的能带
禁带宽度(E_g)：E_c - E_v，决定半导体性质
Si: E_g=1.12eV   Ge: E_g=0.66eV   GaAs: E_g=1.43eV

导体：导带部分填充 / 价带导带重叠
半导体：禁带窄(0.1~3eV)，价带满/导带空
绝缘体：禁带宽(>3eV)

温度升高 → 晶格间距增大 → 禁带宽度减小（如Si: dE_g/dT ≈ -2.3×10⁻⁴ eV/K）
3
有效质量
★★★★★

电子在周期性势场中的运动等效为自由粒子在有效质量下的运动。

m* = ħ² / (d²E/dk²)

E-k关系：描述能量与波矢的关系。导带底附近E-k曲线开口向上 → m*>0（正有效质量）；价带顶附近开口向下 → m*<0（负有效质量）。

有效质量 = 晶格对电子作用的宏观体现。m*越小，电子越"轻"，越容易被加速，迁移率越高。
4
空穴
★★★★★

定义：价带中缺少一个电子的空位，等效为带+q电荷的准粒子。

运动：空穴速度 = 被缺少电子速度的负值。空穴运动可类比气泡在水中上升。

等效质量：空穴具有正的有效质量（价带顶附近）。

电导率贡献：σ = q(nμ_n + pμ_p)
Si中: μ_n≈1400, μ_p≈500 cm²/(V·s)
空穴不是真实粒子，是价带中大量电子集体运动的等效描述。
5
本征半导体与杂质半导体
★★★★☆

本征半导体：纯净、无缺陷，载流子仅由热激发产生，n=p=n_i。

施主杂质(如P, As, Sb掺Si)：提供电子 → n型半导体。施主能级靠近导带底。

受主杂质(如B, Ga, In掺Si)：提供空穴 → p型半导体。受主能级靠近价带顶。

深能级杂质：在禁带中部，常作复合中心（缩短少子寿命）。

类氢模型电离能：
E_d = (m*/m₀) × (1/ε_r²) × 13.6 eV
Si中: ε_r=11.7, m*≈0.26m₀ → E_d ≈ 0.026 eV（浅能级）
6
晶体结构与缺陷
★★★★☆

替位式杂质：占据晶格原子位置（如P在Si中）。

间隙式杂质：位于晶格间隙（如C, N在Si中）。

点缺陷：空位（缺少原子）、间隙原子（多余原子）。

线缺陷(位错)：刃型位错、螺旋位错。位错处可形成受主能级。

面缺陷：晶界、层错。

杂质补偿：同时有施主和受主时，有效掺杂 = |N_D - N_A|。N_D > N_A → n型。

🔗 章内知识关联

  • 能带形成 ← 原子共有化运动 → 分立能级分裂为准连续能带
  • 有效质量 = f(E-k关系) → 直接决定迁移率 → 影响电导率
  • 空穴 = 价带缺失电子的等效 → 贡献电导率p·μ_p
  • 杂质电离能 = f(m*, ε_r) → 浅能级全电离 → 多子浓度≈杂质浓度
  • 深能级→ 复合中心/陷阱 → 影响少子寿命（第5章核心）

第2章 半导体中的杂质和缺陷能级

杂质电离与缺陷态

权重80%★★★★
📊 知识关系图 — 第2章
1
替位式与间隙式杂质
★★★★☆

替位式：杂质原子替代晶格原子（如P→Si），形成共价键。要求杂质原子半径与基体原子相近。

间隙式：杂质原子位于晶格间隙（如C→Si），不破坏原共价键。

III-V族杂质在IV族半导体中为替位式；C、N等小原子为间隙式。

2
施主与受主能级
★★★★★

施主(n型掺杂)：提供电子，能级位于禁带上半部，靠近导带底。

受主(p型掺杂)：提供空穴，能级位于禁带下半部，靠近价带顶。

浅能级：电离能小(~meV级)，室温下完全电离。

深能级：电离能大，禁带中部，作复合中心或陷阱。

Si中施主电离能: P→0.045eV, As→0.054eV, Sb→0.039eV
Si中受主电离能: B→0.045eV, Ga→0.067eV, In→0.16eV
3
杂质补偿效应
★★★★☆

同时存在施主和受主时：有效杂质浓度 = |N_D - N_A|

N_D > N_A → n型，多子电子 n₀ ≈ N_D - N_A
N_A > N_D → p型，多子空穴 p₀ ≈ N_A - N_D

即使N_D和N_A都很大，只要|N_D-N_A|小，载流子浓度仍很低。这就是"杂质补偿"。
4
深能级与缺陷态
★★★★☆

深能级：禁带中部，同时具有施主和受主特性。

复合中心：俘获电子和空穴的效率相近 → 促进复合 → 缩短少子寿命。

陷阱中心：俘获一种载流子后又释放 → 载流子暂存效应。

位错：刃型位错在滑移面上有过剩原子/空位 → 形成浅受主能级。

深能级的复合/陷阱作用直接影响器件响应速度和噪声性能。
  • 施主/受主能级位置 → 决定杂质电离能 → 决定室温下载流子浓度
  • 深能级 → 复合中心 → 影响第5章少子寿命τ → 影响PN结特性

第3章 半导体中载流子的统计分布

载流子浓度计算核心 — 高频考点

权重98%★★★★★
📊 知识关系图 — 第3章
1
费米分布函数
★★★★★
f(E) = 1 / [1 + exp((E - E_F) / k₀T)]

E_F（费米能级）：电子占据概率=1/2的能量位置。

E < E_F：占据概率>1/2；E > E_F：占据概率<1/2。

玻尔兹曼近似：当E - E_F ≥ 3kT时，f(E) ≈ exp(-(E-E_F)/kT)。室温k₀T ≈ 0.026eV。

费米分布是量子统计（考虑泡利不相容原理），玻尔兹曼分布是经典近似。
2
状态密度
★★★☆☆
导带底：g_c(E) = (4π(2m*_n)^(3/2) / h³) × √(E - E_c)
价带顶：g_v(E) = (4π(2m*_p)^(3/2) / h³) × √(E_v - E)

有效态密度：N_c = 2(2πm*_n kT / h²)^(3/2)，N_v = 2(2πm*_p kT / h²)^(3/2)

室温Si: N_c ≈ 2.8×10¹⁹ cm⁻³, N_v ≈ 1.04×10¹⁹ cm⁻³

椭球等能面 → 影响有效质量 → 影响N_c、N_v

3
本征载流子浓度
★★★★★
n_i² = N_c · N_v · exp(-E_g / k₀T)
Si@300K: n_i ≈ 1.5×10¹⁰ cm⁻³
Ge@300K: n_i ≈ 2.4×10¹³ cm⁻³
GaAs@300K: n_i ≈ 2×10⁶ cm⁻³

质量作用定律：n · p = n_i²（热平衡时恒成立）

温度↑ → E_g↓ + exp项↑ → n_i急剧增大

易错：n_i² = N_c·N_v·exp(-Eg/kT)，不是n_i = ...
4
杂质半导体载流子浓度
★★★★★
n型(完全电离)：n₀ ≈ N_D, p₀ = n_i²/N_D
p型(完全电离)：p₀ ≈ N_A, n₀ = n_i²/N_A
电中性条件：n + N_A = p + N_D

三个温区：
① 低温弱电离：杂质部分电离
② 饱和区(室温)：杂质完全电离，本征激发可忽略
③ 高温本征区：本征激发占主导

易错：掺杂计算注意数量级！Si原子密度~5×10²²cm⁻³，"百万分之一掺杂"= 5×10¹⁶cm⁻³
5
费米能级定位
★★★★★
n型: E_F - E_i = k₀T·ln(n₀/n_i) → E_F靠近导带
p型: E_i - E_F = k₀T·ln(p₀/n_i) → E_F靠近价带
E_F = E_c - k₀T·ln(N_c/N_D)

N_D↑ → E_F向导带移动；N_D足够大 → E_F进入导带 → 简并半导体

定性规律：掺杂越重，E_F越靠近多子能带边缘。
6
简并与非简并半导体
★★★☆☆

非简并：E_F在禁带中，可用玻尔兹曼近似。

简并：E_F进入导带/价带，费米-狄拉克统计不可简化。

禁带变窄效应：重掺杂时能带尾态形成，有效E_g减小。

判据：E_F距能带边缘 < 3kT → 简并；> 3kT → 非简并
  • 费米分布 × 状态密度 → 积分得到载流子浓度
  • 费米能级位置 → 决定第4章电导率 → 决定第5章非平衡载流子分布
  • 质量作用定律np=n_i² → 贯穿全书，PN结/MOS分析的基础

第4章 半导体的导电性

载流子输运与散射机制

权重90%★★★★★
📊 知识关系图 — 第4章
1
漂移运动与漂移电流
★★★★★
漂移速度: v_d = μE
漂移电流密度: J = q(nμ_n + pμ_p)E
电导率: σ = q(nμ_n + pμ_p)
电阻率: ρ = 1/σ

迁移率μ = qτ/m*：单位电场下的平均漂移速度。

n型近似: σ ≈ qN_Dμ_n；p型近似: σ ≈ qN_Aμ_p

室温Si: μ_n≈1400, μ_p≈500 cm²/(V·s)；GaAs: μ_n≈8500 cm²/(V·s)
2
散射机制
★★★★★

晶格振动散射(声子散射)：μ_L ∝ T^(-3/2)，随温度升高而降低。
机理：晶格热振动→周期势场畸变→载流子被散射。

电离杂质散射：μ_I ∝ T^(3/2)/N_I，随温度升高而增大。
机理：电离杂质库仑势场→载流子被偏转。

总迁移率：1/μ = 1/μ_L + 1/μ_I

低温：电离杂质散射主导→μ随T↑↑；高温：晶格散射主导→μ随T↓
3
迁移率影响因素
★★★★★

温度：低温电离杂质主导(μ随T↑)；高温晶格散射主导(μ随T↓)

杂质浓度：浓度↑ → 电离杂质数↑ → 散射↑ → μ下降

有效质量：m*↓ → μ↑（GaAs电子迁移率远高于Si）

μ ≈ μ_L（本征区）
μ ≈ μ_I（重掺杂区）
典型: Si掺杂10¹⁷cm⁻³时, μ_n从~1400降至~700 cm²/(V·s)
4
爱因斯坦关系
★★★★★
D/μ = k₀T/q ≈ 0.026V (室温)

D：扩散系数(cm²/s)；μ：迁移率(cm²/(V·s))

物理意义：建立扩散运动(D)与漂移运动(μ)之间的联系。

Si@300K: D_n ≈ 36 cm²/s, D_p ≈ 12 cm²/s

爱因斯坦关系是连接第4章(漂移)与第5章(扩散)的桥梁。
5
强电场效应
★★★☆☆

热载流子：强电场(E>10³V/cm)下，载流子获得能量>>k₀T，漂移速度偏离线性。

速度饱和：高电场下载流子速度趋于饱和值(~10⁷cm/s)。

负微分电导：多能谷半导体(如GaAs)在特定电场范围，漂移速度随电场增大而减小。

耿氏效应：利用负微分电导产生微波振荡。

  • 电导率σ = q(nμ_n+pμ_p) → 由第3章载流子浓度 + 第4章迁移率共同决定
  • 散射机制→ 决定μ的温度/浓度依赖 → 决定半导体器件的工作温度范围
  • 爱因斯坦关系 → 连接第4章漂移与第5章扩散 → 为PN结分析提供基础

第5章 非平衡载流子

产生、复合、扩散 — 衔接理论与器件

权重92%★★★★★
📊 知识关系图 — 第5章
1
非平衡载流子概念
★★★★★

外界作用(光照/注入) → 打破热平衡 → 额外产生载流子Δn=Δp

稳态条件: Δp = g · τ（g=产生率, τ=寿命）
衰减规律: Δp(t) = Δp(0) · exp(-t/τ)

少子寿命τ：非平衡载流子从产生到复合的平均时间。

非平衡状态下，多子浓度变化可忽略(Δn≪n₀)，仅少子浓度显著变化！
2
准费米能级
★★★★☆
n = n_i·exp((E_Fn - E_i)/k₀T)
p = n_i·exp((E_i - E_Fp)/k₀T)

平衡时：E_Fn = E_Fp = E_F（统一费米能级）

非平衡时：E_Fn > E_F > E_Fp（n型），两者分离

分离越大 → 非平衡程度越强 → 复合驱动力越大

3
复合机制
★★★★☆

直接复合(本征复合)：电子直接从导带跃迁到价带。Δp(t)=Δp₀·exp(-t/τ_direct)。直接带隙半导体主导。

间接复合(通过复合中心)：经禁带中深能级中转。Shockley-Read-Hall模型。间接带隙半导体主导。

表面复合：半导体表面缺陷促进复合。表面复合速度S描述。

Si(间接带隙)中间接复合为主；GaAs(直接带隙)中直接复合为主。
4
扩散运动与扩散长度
★★★★★
扩散电流密度:
J_n(diff) = qD_n(dn/dx), J_p(diff) = -qD_p(dp/dx)
扩散长度: L = √(Dτ)

L的物理意义：非平衡载流子在复合前扩散的平均距离。

Si@300K: L_n≈√(36×10⁻⁵)≈60μm, L_p≈√(12×10⁻⁵)≈35μm

5
连续性方程
★★★★★
∂p/∂t = -D_p·∂²p/∂x² + μ_p·E·∂p/∂x + μ_p·p·∂E/∂x + g - Δp/τ

四项物理含义：扩散项 + 漂移项 + 电场变化项 + 产生复合项

一维稳态：D_p·d²p/dx² - μ_p·E·dp/dx + Δp/τ = 0

连续性方程是分析PN结、MOS器件电流的数学基础。
  • 准费米能级分离程度 → 反映非平衡态 → 连接第3章费米能级
  • 扩散长度L = √(Dτ) → 由第4章D和第5章τ共同决定
  • 连续性方程 → 直接用于第6章PN结扩散电流推导

第6章 PN结

半导体器件的基础 — 核心中的核心

权重96%★★★★★
📊 知识关系图 — 第6章
1
PN结形成与空间电荷区
★★★★★

p型与n型半导体接触 → 多子扩散 → 界面附近留下不可移动的电离杂质 → 空间电荷区(耗尽层)

空间电荷区 → 内建电场 → 阻止多子扩散 → 达到动态平衡

接触电势差: V_D = (k₀T/q)·ln(N_D·N_A / n_i²)
势垒高度: qV_D（能量单位eV）
易错：V_D是电压(V)，qV_D是能量(eV)，不要混淆！
2
PN结电流-电压特性
★★★★★
肖克莱方程: I = I_s · [e^(qV/k₀T) - 1]
I_s = qA(D_p·p_n₀/L_p + D_n·n_p₀/L_n)

正偏(V>0)：势垒↓ → 多子扩散主导 → 电流指数增长

反偏(V<0)：势垒↑ → 少子漂移主导 → 反向饱和电流I_s（很小）

这体现了单向导电性。

3
势垒宽度
★★★★★
X_D = √[2ε₀ε_r(V_D-V)/q · (N_A+N_D)/(N_AN_D)]
正偏: V>0 → X_D减小
反偏: V<0 → X_D增大

非对称简化：N_D≫N_A时，X_D ≈ √(2ε₀ε_rV_D / qN_A)，势垒主要在轻掺杂侧。

4
击穿机制
★★★★☆

雪崩击穿：碰撞电离 → 载流子倍增。V_br>6V，正温度系数。可逆。

齐纳击穿：强电场隧道效应。V_br<4V，负温度系数。可逆。

热击穿：功耗→温升→正反馈。不可逆，器件烧毁。

判断：高掺杂→齐纳(<4V)；低掺杂→雪崩(>6V)；中间：两者混合。
5
PN结电容
★★★★☆

势垒电容C_T：耗尽层宽度随偏压变化 → 类似平板电容。反偏主导。

C_T = εA/X_D，反偏↑ → X_D↑ → C_T↓

扩散电容C_D：扩散区载流子存储变化。正偏主导。

反偏主要考虑C_T；正偏主要考虑C_D。
  • V_D公式中的n_i → 由第3章 n_i² = N_cN_v·exp(-Eg/kT) 决定
  • 肖克莱方程中的I_s → 由第5章扩散长度L和扩散系数D决定
  • 势垒宽度X_D → 由第6章空间电荷区分析决定 → 影响第6章电容特性

第7章 金属和半导体接触

肖特基势垒与欧姆接触

权重75%★★★★
📊 知识关系图 — 第7章
1
功函数与接触类型
★★★★☆

金属功函数W_m：电子从费米能级逸出到真空所需能量。

半导体功函数W_s = χ + (E_c - E_F)，χ为电子亲和能。

肖特基接触(阻挡层):
n型: W_m > W_s → 电子流向金属 → 表面耗尽
p型: W_m < W_s → 空穴流向金属 → 表面耗尽

欧姆接触(反阻挡层):
n型: W_m < W_s → 表面积累
p型: W_m > W_s → 表面积累
2
肖特基二极管
★★★★☆

整流特性：正向导通，反向截止。

电流机制：热电子发射为主（重掺杂时隧道效应也参与）。

优势：无少子存储效应 → 开关速度快；正向压降低(~0.3V vs PN结0.7V)。

应用：高速开关、微波混频、功率器件。
3
欧姆接触
★★★★☆

线性I-V特性：电流与电压成正比，双向导通。

实现方法：选择合适功函数的金属 → 表面积累；或重掺杂 → 隧道效应。

应用：器件电极（晶体管源漏电极、PN结电极）。

实际器件中欧姆接触的接触电阻需尽量小，否则影响器件性能。

第8章 MIS/MOS结构

表面效应与电容特性 — MOSFET基础

权重88%★★★★★
📊 知识关系图 — 第8章
1
表面电场效应
★★★★★

以p型半导体MIS结构为例：

积累区(V_G<0)：多子空穴在表面积累

耗尽区(V_G>0)：表面空穴被排斥，形成耗尽层

反型区(V_G>V_T)：表面少子浓度 > 体内多子浓度

强反型判据: ψ_s ≥ 2φ_F（φ_F为费米势）
2
MIS结构C-V特性
★★★★★

理想高频C-V：积累区C=C_ox；耗尽区C↓；反型区C维持最小值(反型层响应慢)

理想低频C-V：反型区C回升至C_ox(反型层跟得上信号)

实际影响：

  • 固定正电荷 → C-V向负方向平移
  • 可动离子(如Na⁺) → C-V沿电压轴漂移
  • 界面态 → C-V曲线拉伸变形
3
阈值电压
★★★★★
V_T = V_FB + 2φ_F + Q_B/C_ox
V_FB = φ_ms - Q_f/C_ox（平带电压）
φ_F = (k₀T/q)·ln(N_A/n_i)（费米势）
C_ox = ε₀ε_ox/t_ox（氧化层电容）

影响因素：氧化层电荷、体效应、功函数差。

计算题常见：给定t_ox、ε_ox、N_A，求V_T。注意单位换算(nm→cm)。
4
Si-SiO₂系统电荷
★★★★☆

固定电荷(Q_f)：氧化层中过剩Si⁺，位置固定，不随偏压变化。

可动离子(Q_m)：Na⁺、K⁺等碱金属离子，在氧化层中可移动。

界面态(D_it)：Si-SiO₂界面悬挂键，可俘获/释放载流子。

MOS器件制造中需严格控制Na⁺污染和界面态密度。
  • 表面电场效应 → 是MOSFET工作原理的基础
  • C-V特性 → 用于提取半导体参数(掺杂浓度、氧化层电荷等)
  • 阈值电压 → MOSFET的核心参数，决定器件开启/关断

第9章 异质结、光学性质与特殊效应

应用热点与概念补充 (30%分值)

权重70%★★★
📊 知识关系图 — 第9章
1
异质结
★★★☆☆

定义：两种禁带宽度不同的半导体形成的结（如AlGaAs/GaAs）。

核心差异：存在能带偏移（ΔE_c导带阶、ΔE_v价带阶）。

高注入比：宽禁带→窄禁带注入势垒低 → 注入效率高。

超注入：异质结可使注入载流子浓度超过平衡浓度。

同质结 vs 异质结：核心区别是材料禁带宽度不同。
2
光吸收与光电效应
★★★★☆

本征吸收：hν ≥ E_g → 电子从价带跃迁到导带。

光电导效应：光注入非平衡载流子 → 电导率增大 → 光敏电阻。

光生伏特效应：PN结吸收光子 → 内建电场分离载流子 → 形成开路电压。

太阳能电池: P_max = V_OC · I_SC · FF
直接带隙发光效率 >> 间接带隙（无需声子参与）
3
霍尔效应
★★★★☆
V_H = R_H · I · B / d
R_H = 1/(qn) (n型) 或 R_H = -1/(qp) (p型)
n = 1/(q|R_H|d)

应用：测量载流子浓度和类型（V_H正→p型，V_H负→n型）。

实验：改变B和I方向，消除副效应（如爱廷豪森效应）。

4
其他效应与非晶态半导体
★★☆☆☆

压阻效应：应力→电阻率变化 → 压力传感器。

热电效应：温差→电压（塞贝克效应）→ 温差发电。

非晶态半导体：长程无序、短程有序；带尾态、迁移率边。

应用：非晶硅太阳能电池、薄膜晶体管。
